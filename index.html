几步，把好资源用起来。

先选择你的客户端，再查看对应的资源与使用说明。

发现与预览

选择 Surge、Egern 或 Mihomo，通过分类或搜索找到资源。卡片标明适用客户端，点击「查看配置」确认格式与说明。

Surge：使用规则集

点击「查看配置」，填写已有策略或策略组，复制 RULE-SET 引用到当前配置的 [Rule] 区域，并放在 FINAL 规则之前。引用直接指向上游，Surge 可继续获取上游更新。 卡片上的「复制链接」可复制原始规则集地址。

Surge：安装功能模块

在已安装 Surge 的设备上，点击模块卡片的「一键导入」即可打开 Surge 安装入口；详情中也保留「导入 Surge」。 你还可以复制源链接、预览完整内容，或下载 .sgmodule 文件后在 Surge 中打开并安装。

Egern：小组件、规则与模块

点击 Egern 模块或小组件卡片的「一键导入」，即可打开 Egern 模块添加入口，带入名称和源链接。规则集请在「查看配置」中填写已有策略，复制 YAML 引用并合并到当前配置。小组件安装后仍需按作者说明设置参数，再从 iOS 主屏幕添加 Egern 小组件。

Mihomo：使用 YAML 规则集

选择「Mihomo」浏览仓库规则。打开「查看配置」并填写已有策略组，复制 YAML，把 rule-providers 合并到同名映射，把 rules 条目合并到已有列表并放在 MATCH 之前。保留单个顶层字段，不要用规则片段覆盖完整配置；provider 使用 classical 与 yaml 格式。卡片支持复制源链接、预览和下载原始规则。

更多客户端：原生远程规则

选择 Quantumult X、Loon、Shadowrocket、Stash 或 Sing-box 后，打开规则卡片中的「查看配置」，复制该客户端对应的远程规则或配置片段，再合并到现有配置。Quantumult X 的「重写」与 Loon 的「插件」分类目前为空；小组件仅适用于 Egern。
